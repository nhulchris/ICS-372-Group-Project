# Brew & Bite Cafe System

## Team Members
- Chris Nhul
- Garvin Yau
- Salman Ahmed

## Project Description
JavaFX-based cafe ordering system implementing MVC architecture, Observer Pattern, and Factory Method Pattern.

## Tech Stack
- Java 21
- JavaFX 26
- JSON (Gson or Jackson)
- Maven

## Features
- Customer ordering
- Barista fulfillment
- Manager inventory system

## How to run
- From command line, 
`mvc javafx:run`
